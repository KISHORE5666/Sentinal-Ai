# SentinelAI

## Overview
SentinelAI is an AI-powered Security Information and Event Management (SIEM) platform designed to assist Security Operations Center (SOC) analysts in detecting, investigating, and responding to cybersecurity threats.

## Features
- Log Collection & Monitoring
- Real-Time Threat Detection
- AI-Assisted Incident Analysis
- Threat Intelligence Integration
- Alert Correlation
- Incident Response Dashboard

## Technologies Used
- Python
- Flask
- SQLite/MySQL
- Machine Learning
- REST APIs
